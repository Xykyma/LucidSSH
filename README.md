SSH-клиент для Windows и Linux, который объясняет что происходит и не даёт случайно сломать сервер.

> Версия **1.1.0** добавляет Linux x64 (AppImage и `.deb`) и Windows portable. Инструкции для них приведены ниже; скачивай только артефакты, уже опубликованные в [Releases](https://github.com/Xykyma/LucidSSH/releases).

---

## Зачем ещё один SSH-клиент

PuTTY надёжный, но не объясняет ошибки и не предупреждает об опасных командах. Termius красивый, но требует подписку и аккаунт, а ключи уходят в облако. MobaXterm перегружен возможностями, которые нужны раз в год.

LucidSSH занимает другую нишу: он для тех, кто управляет одним-двумя серверами, не является профессиональным сисадмином и хочет понимать что происходит — без лишних усилий.

---

## Ключевые возможности

### Страж опасных команд

Перед выполнением `rm -rf`, `dd`, `mkfs`, `chmod 777` и подобных команд приложение останавливает выполнение и объясняет по-русски что именно произойдёт. Для подтверждения нужно вручную ввести имя удаляемого объекта — не просто нажать «ок». Страж предупреждает о **распознанных** опасных командах; это помощь против случайной ошибки, а не гарантия от любого разрушительного действия.

![Страж опасных команд](docs/assets/guard_ru.png)

### Детектор ошибок

После каждой неудачной команды появляется панель с объяснением. `Permission denied` — получишь список причин и конкретные проверки. `Connection refused` — узнаешь чем это отличается от `Connection timed out`. Работает офлайн, по встроенной базе, без отправки данных куда-либо.

![Детектор ошибок](docs/assets/error_ru.png)

### Breadcrumb «где я» и мини-дашборд сервера

Над терминалом всегда видно: к какому серверу подключён, под каким пользователем, в какой папке. Каждый элемент пути кликабелен — вставляет путь в строку ввода. Root-сессия выделяется красным. Рядом — компактная строка CPU/RAM/диска/пинга, обновляется каждые 10 секунд через фоновый канал и не мешает основной работе.

![Breadcrumb и мини-дашборд](docs/assets/breadcrumbs-dashboard_ru.png)

### Каталог команд

Боковая панель с объяснениями на русском языке: что делает команда, какие флаги для чего, примеры. Клик по флагу вставляет команду в терминал. Поиск по-русски: «удалить» найдёт `rm`.

![Каталог команд](docs/assets/catalog_ru.png)

### История с заметками

Все команды сохраняются локально с временем, именем хоста и exit code. К любой записи можно добавить заметку. Поиск по командам и заметкам. Типичные секреты (пароли, токены, ключи в команде) маскируются перед сохранением.

### Полностью локально

Никакого аккаунта, никакого облака, никакой телеметрии. Пароли хранятся в системном хранилище паролей (Windows Credential Manager, на Linux — Secret Service). Приватные ключи остаются там, где лежат — приложение не копирует их к себе. Единственные внешние соединения — SSH к твоим серверам и проверка обновлений по HTTPS.

## Установка

### Windows

1. Скачай `LucidSSH-Setup-1.1.0-x64.exe` со страницы [Releases](https://github.com/Xykyma/LucidSSH/releases).
2. Проверь целостность файла по SHA-256 — контрольная сумма опубликована в описании релиза.
3. Запусти установщик.

#### Portable (начиная с 1.1.0)

Скачай `LucidSSH-Portable-1.1.0-x64.exe`, сверь SHA-256 и положи его в отдельную папку с правом записи. Установка и права администратора не нужны. Настройки, хосты, история, `known_hosts` и резервные копии хранятся рядом с exe; для переноса профиля закрой приложение и перенеси всю папку, включая `profile.id`.

Пароли и passphrase остаются в Windows Credential Manager и **не переносятся папкой на другой ПК или к другому пользователю** — их потребуется ввести заново. Приватные ключи не копируются: на другом ПК проверь путь к исходному ключу. Файлы профиля не шифруются; portable не обещает отсутствие служебных следов в ОС.

Обновление — вручную: при закрытом приложении замени только exe новым файлом из Releases, сохранив остальные файлы профиля. Не удаляй и не пересоздавай `profile.id`.

**О предупреждении Windows SmartScreen.** Версии 1.0 и 1.1 выпускаются без сертификата подписи кода — возврат к подписи отложен на отдельное будущее решение. Поэтому Windows может показать предупреждение «Windows защитила ваш компьютер». Само предупреждение не доказывает ни опасность, ни безопасность файла. Если доверяешь источнику и решил продолжить, Windows предлагает «Подробнее» → «Выполнить в любом случае». Сверь SHA-256 из релиза со скачанным файлом: это проверяет целостность, но не защищает от подмены самого GitHub Release.

### Linux

Linux x64 поставляется в форматах AppImage и `.deb` начиная с 1.1.0. Перед скачиванием проверь, что выбранный релиз уже содержит Linux-артефакты.

Скачай сборку со страницы [Releases](https://github.com/Xykyma/LucidSSH/releases):

- **`.deb`** — рекомендуется для Ubuntu и Debian: `sudo apt install ./LucidSSH-1.1.0-amd64.deb`. Обновляется вручную — скачай новую версию со страницы Releases (кнопка в «О программе» откроет её).
- **`.AppImage`** — `LucidSSH-1.1.0-x86_64.AppImage`: `chmod +x` и запуск. Поддерживает автообновление; скачивание и установка — с согласия пользователя. Фактическая установка AppImage-обновления пока не проверена, проверка запланирована на первый релиз с Linux-артефактами.

Перед запуском любого Linux-пакета сверь SHA-256 с описанием релиза.

Для сохранения паролей нужен Secret Service — gnome-keyring или KWallet (в GNOME и KDE обычно уже есть). Без него приложение работает, но пароли сохранить нельзя: подключайтесь по ключу или вводите пароль каждый раз.

**AppImage на Ubuntu 24.04:**

- Нужен пакет `libfuse2t64`: `sudo apt install libfuse2t64`. Без него AppImage не запускается. (На Ubuntu 22.04 пакет называется `libfuse2`; сборка на 22.04 не тестировалась — проверено на 24.04.)
- AppArmor в Ubuntu 23.10+ запрещает непривилегированные user namespaces, и AppImage с Electron может не стартовать. Самый простой выход — поставить `.deb`. Если нужен именно AppImage, создай профиль `/etc/apparmor.d/lucidssh` (подставь свой путь к файлу):

  ```
  abi <abi/4.0>,
  include <tunables/global>
  profile lucidssh /home/USER/Applications/LucidSSH-*.AppImage flags=(unconfined) {
    userns,
  }
  ```

  и примени его: `sudo apparmor_parser -r /etc/apparmor.d/lucidssh`. Флаг `--no-sandbox` не используем — он ослабляет изоляцию окна.

Для мастера создания ключа нужен `ssh-keygen`: `sudo apt install openssh-client`.

### Системные требования

- Windows 10 (версия 1903+) или Windows 11, x64; либо Linux x64. Linux-сборки проверены на Ubuntu 24.04; Ubuntu 22.04, Debian 12 и другие дистрибутивы отдельно не проверены.
- 200 МБ RAM в простое

## Приватность

LucidSSH не собирает телеметрию, не требует аккаунта и не отправляет данные никуда, кроме твоих собственных серверов. Единственный исходящий трафик, который приложение инициирует само:

- SSH-соединения к хостам, которые ты добавил;
- в NSIS-версии и AppImage — проверка новых версий на GitHub Releases (по запросу и при включённой автопроверке при старте, не блокирует работу). Portable и `.deb` не вызывают автообновление — они предлагают открыть Releases в системном браузере.

Пароли хранятся в системном хранилище паролей: Windows Credential Manager или Secret Service (gnome-keyring, KWallet) на Linux. Приватные ключи не копируются в директорию приложения — используется оригинальный путь на диске.

---

## Что пока не входит в приложение

SFTP-браузер, Mosh, Telnet, RDP, VNC, X11, Serial, облачная синхронизация, мобильная версия — запланированы в следующих версиях или не планируются вовсе.

Локальные ИИ-объяснения (офлайн, без облака) запланированы в одной из следующих версий: они будут дополнять встроенные базы для редких команд и нестандартных ошибок. Сейчас мгновенную ценность дают встроенные базы команд и ошибок — без скачивания моделей и настройки.

Светлая тема, дополнительные хоткеи, абсолютный путь в диалоге Стража и плейсхолдеры в сниппетах запланированы после 1.1.0; точные версии пока не назначены.

## Лицензия

Исходный код открыт для просмотра, но **не лицензирован** для использования, копирования, модификации или распространения без явного разрешения автора (все права защищены). Причина — проект в процессе поиска модели монетизации, и открытая лицензия ограничила бы будущие варианты. Если тебе интересно использовать код LucidSSH в своём проекте — напиши, обсудим.
